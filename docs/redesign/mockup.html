HandStrudel — proposed structure

The change isn't the paint, it's the bones. Four real destinations via a tab bar instead of one linear flow + a junk-drawer sheet. Play gets a persistent control deck. Loops becomes a first-class place for the capture→layer→arrange flow. Sounds holds presets + store. Tune is the small set you change mid-session; everything power-user folds under Advanced.

Tune. Only the few things you change mid-session: key, scale, effects. The entire old mega-sheet (mapping, dual drums, sequencer, code) collapses under one Advanced row. Players never see the cockpit unless they want it.

This is a static mockup of structure, not final visuals — colors/spacing follow the design tokens already in the branch. The point is the architecture: 4 destinations, a persistent play deck, a real Loops flow, and a tiny Tune surface. Tell me where this is wrong and I'll change the map before touching more code.
